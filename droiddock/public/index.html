Help

These notes describe the current DroidDock controls. Opening Help does not send input to the phone. Help stays available while disconnected.

Pointer

  • Tap, drag, long-press, and scroll on the live phone video.
  • Phone controls stay unavailable until a live frame appears.

Keyboard

  • Focus the phone screen to type. Backspace, Enter, and arrows go to the phone.
  • Tab stays in the browser. It does not send a Tab key to the phone.
  • Browser shortcuts that use Ctrl, Alt, or Command stay in the browser.
  • DroidDock does not add global shortcut interception.

Escape

  • Escape closes Help and returns focus to Help.
  • Escape then closes Details and returns focus to Details and text input.
  • Escape that exits fullscreen does not send Android Back.
  • With Help and Details closed, and the phone screen focused, Escape sends Back.

Paste

  • Press Ctrl+V over the focused phone screen to paste plain text.
  • Unicode, emoji, and multiline text are supported when the Android app accepts them, up to 64 KiB of UTF-8.
  • Paste changes the phone clipboard. Images and files are not supported.

Fallback text

  • Open Details and text input for fallback text. It uses scrcpy text injection.
  • Supports ASCII and some accented letters, not every Unicode character.
  • Limited to 300 UTF-8 bytes per send. A live N / 300 bytes counter uses the same check as Send.
  • Over-limit text stays in the field so it can be shortened.

Stream statistics

  • Details can show optional local stream statistics: media bytes received, decoded frames drawn, and decode queue length.
  • Those numbers stay in this tab and are not sent anywhere. They are not end-to-end latency and do not prove video is visible.
  • Configured encoder limits are listed separately from measured rates. A still phone screen may produce few frames.

Phone PIN entry

Open the PIN prompt on your phone first. Protected screens may stay black. Digits go to the focused phone field; some phones submit automatically. Unsupported prompts need the physical phone.
